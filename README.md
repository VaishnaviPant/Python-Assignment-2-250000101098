## Topics Covered in Detail

The 50 programs are organized around the following Python programming concepts:

1. **Arithmetic Operators** – Addition, subtraction, multiplication, division, floor division, modulus and compound assignment operators.
2. **Relational Operators** – Comparing values using equality, inequality and comparison operators.
3. **Logical Operators** – Understanding AND, OR and NOT operations.
4. **Bitwise Operators** – Bitwise AND, OR, XOR, left shift and right shift.
5. **Membership Operators** – Using `in` and `not in`.
6. **Identity Operators** – Understanding `is` and `is not`.
7. **Operator Precedence** – Evaluating expressions involving multiple operators.
8. **Conditional Statements** – Using if, if-else, if-elif-else and nested if statements.
9. **Decision-Making Programs** – Checking numbers, leap years, voting eligibility, grades and divisibility.
10. **Loops** – Using for loops and while loops for repetitive operations.
11. **Number-Based Programs** – Factorial, prime numbers, reversing integers and digit calculations.
12. **Nested Loops** – Generating number patterns, star patterns and multiplication tables.
13. **Loop Control Statements** – Understanding break, continue and pass.
14. **Loop Else Clause** – Demonstrating else with for and while loops.

## Execution Instructions

### Prerequisites

- **Python Version:** Python 3.8 or higher
- **Editor:** Visual Studio Code (VS Code)
- **Dependencies:** No external libraries are required. All programs use the Python standard library.

### Run a Program

Open a terminal in the repository folder and execute an individual Python file:

```bash
python Q01.py
```

On systems where Python 3 is invoked separately, use:

```bash
python3 Q01.py
```

Replace `Q01.py` with the desired question number to execute another program.

Programs that require user input will prompt for the necessary values in the terminal.
